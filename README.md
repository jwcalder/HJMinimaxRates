# Hamilton-Jacobi Equation Minimax Estimation Rates

This repository reproduces the results from the paper

Calder, J. and Lu, Y. 2026. [Minimax rates for interpolating solutions of Hamilton-Jacobi
equations from data](https://arxiv.org/abs/). arXiv preprint arXiv.

The python script `rates.py` runs the experiments, and has variables to select equation and other parameters at the top of the script. The plots of solutions are generated with `solution_plots.py`. The data from experiments is saved in the `data` folder and figures in the `figures` folder.
